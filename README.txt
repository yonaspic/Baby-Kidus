# የቅዱስ አብርሃም የጥምቀት ግብዣ

A mobile-friendly Amharic Ethiopian Orthodox Christian baby baptism invitation, built with plain HTML/CSS/JavaScript for GitHub Pages.

## Files
- `index.html` — complete website
- `images/` — add your baby/family photos here
- `music.mp3` — optional background music (you add this file yourself)

## Add your photos
Copy up to four photos into the `images` folder and name them exactly:
- `baby1.jpg`
- `baby2.jpg`
- `baby3.jpg`
- `baby4.jpg`

JPG is recommended. If your photo files are PNG, either convert them to JPG or edit the matching filename in `index.html`.

## Add background music
Place a royalty-free MP3 named `music.mp3` beside `index.html` (not inside `images`). No music button is shown. The page tries autoplay and retries after the visitor's first tap/click/keypress. **Phones and browsers often block autoplay with sound**, so no website can guarantee that music starts without any interaction.

## Publish with GitHub Pages
1. Open your GitHub repository. You can create a new repository named `abraham-baptism-invitation`, or use another repository.
2. Upload `index.html`, the `images` folder, and optionally `music.mp3` to the repository's top level (root). `index.html` must not be inside another folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait a few minutes and open the website URL shown in Settings → Pages. A project site URL normally looks like `https://YOUR-USERNAME.github.io/abraham-baptism-invitation/`.

### Android phone upload
1. Open `github.com` in Chrome and sign in.
2. Open the repository. Tap **Add file → Upload files** (on some screens this may be under the `+` menu).
3. Select `index.html` and upload your photo files too. If uploading a folder is difficult, open the `images` folder in the repository, create it by uploading files with paths like `images/baby1.jpg`, or upload a ZIP on a PC and extract it locally first. GitHub does not publish a ZIP as the website itself.
4. Scroll down and tap **Commit changes**.
5. Repeat for any missing photos or `music.mp3`, then enable Pages using the steps above.

### PC upload
1. Download and extract the ZIP.
2. Open your repository on GitHub.
3. Use **Add file → Upload files** and drag in `index.html`, the `images` folder contents, and optionally `music.mp3`.
4. Commit changes and enable Pages as described above.

## Customize the text
Open `index.html` and edit the name, date, time, location, and invitation message. The date supplied for this version is November 1, 2026, at 2:00 PM in Addis Ababa. Confirm the venue/address before sharing the invitation.
